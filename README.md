# 📊 Data Analytics Project

## 1. Overview

This project demonstrates the complete data analytics workflow, from loading raw data to creating interactive dashboards and presenting business insights.

The project uses Python for data loading, cleaning, and Exploratory Data Analysis (EDA), PostgreSQL for SQL queries, and Power BI for dashboard development. A final report and presentation are also created using Gamma.

**Project Goal:** To transform raw data into meaningful insights through data analysis, visualization, and reporting.

## 7. How to Run the Project

### Prerequisites

Install or set up the following tools:

* Python
* Jupyter Notebook
* PostgreSQL and pgAdmin
* Power BI Desktop

### Execution Steps

1. Clone or download this repository.

2. Open the project folder.

3. Install the required Python libraries:

   ```bash
   pip install pandas numpy matplotlib seaborn jupyter
   ```

4. Open Jupyter Notebook and run the data analysis notebook.

5. Load the cleaned dataset into PostgreSQL.

6. Execute the SQL queries from the `sql` folder.

7. Open the Power BI file (`.pbix`) to explore the dashboard.

8. Review the final report and Gamma presentation.

**Important:** Update the PostgreSQL connection details and dataset paths according to your local setup.
